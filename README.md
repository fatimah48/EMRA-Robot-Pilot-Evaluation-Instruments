# EMRA Robot Pilot Evaluation Instruments

This repository contains the evaluation instruments used in the autism-center pilot study of the **Educational Multimodal Robot Assistant (EMRA)**.

EMRA is a bilingual Arabic–English educational robot designed to support learning and interaction for children with Autism Spectrum Disorder (ASD). The system combines educational activities, conversational interaction, emotion awareness, facial expressions, and physical gestures.

## Evaluation Instruments

The evaluation package contains:

### F1: Child Session Observation Form

Completed by an observer during and immediately after each child’s session. It records:

- Performance in nine educational activity categories
- Prompt level and activity completion
- Attention and willingness to play again
- Conversational behaviour during the Talk session
- Responses to EMRA’s gestures
- Global engagement, attention, affect, and cooperation
- Emotional appropriateness
- Negative reactions, technical issues, and other important events

### F2: Child Preference Form

Completed immediately after the session with educator assistance. It measures:

- The child’s preference regarding playing with EMRA
- The child’s preference regarding talking with EMRA
- Willingness to interact with EMRA again

The form uses simple pictorial response options suitable for children.

### F3: Educator Post-Pilot Questionnaire

Completed once by each participating educator after the pilot. It includes 20 rating-scale items covering:

- Usefulness and educational value
- Emotion-aware and physical interaction
- Arabic and English language performance
- Practical feasibility
- Safety and ease of interruption
- Willingness to use and recommend EMRA

It also includes open questions about strengths, difficulties, and recommended improvements.

### Automatically Logged Fields

EMRA automatically records:

- Educational activity performance
- Response time, attempts, levels, and help requests
- Conversation transcripts
- Text, visual, and fused emotion labels
- Language routing
- Selected robot gestures
- Safety-layer overrides
- Visual-language-model activation
- System latency and technical failures

## Privacy

The instruments use anonymous child identifiers. No child names or personally identifying information should be entered into the forms or published in this repository.

## Research Context

These instruments were developed for the evaluation of EMRA as part of the research project:

> **Design and Evaluation of a Multimodal, Emotion-Aware and Embodied Educational Robot for Children with Autism Spectrum Disorder**

King Fahd University of Petroleum and Minerals (KFUPM).
